회사 홈페이지 수정 및 적용 방법
1. 작업 시작 전 최신 파일 받기
회사 또는 집에서 작업을 시작할 때 프로젝트 폴더로 이동합니다.
cd C:\Users\RND_5\Desktop\yjh\work\homepage\bmp-tech-homepage
최신 파일을 받습니다.
git pull origin main
작업 상태를 확인합니다.
git status

2. 홈페이지 파일 수정 후 로컬 확인
파일을 수정한 후 개발 서버를 실행합니다.
npm run dev
브라우저에서 접속합니다.
http://localhost:3000
수정 내용과 모바일·PC 화면을 확인합니다.
개발 서버 종료:
Ctrl + C
종료 여부를 물으면:
Y

3. 수정 파일을 GitHub에 올리기
git status
git add .
git commit -m "수정 내용 설명"
git push origin main

예시:
git commit -m "reorder homepage sections"
Vercel이 GitHub 변경사항을 감지해서 자동 배포합니다.
잠시 후 아래 주소에 접속합니다.
https://www.bmpretty.com/
이전 화면이 보이면 강력 새로고침합니다.
Ctrl + Shift + R

4. 패키지를 새로 설치한 경우
npm install nodemailer처럼 패키지를 추가했다면 다음 파일도 함께 GitHub에 올라가야 합니다.
package.json
package-lock.json
다른 컴퓨터에서 최신 프로젝트를 받은 후에는 다음 명령을 실행합니다.
npm install

문의하기 메일 수정 방법
Vercel 프로젝트의 Environment Variables로 들어갑니다.
가능하면 팀 공통 설정이 아니라 아래 프로젝트 내부에서 변경합니다.
bmp-tech-homepage → Environment Variables
현재 문의 메일과 관련된 환경 변수:
SMTP_HOST
SMTP_PORT
SMTP_USER
SMTP_PASSWORD
CONTACT_EMAIL

수신 메일 주소만 바꾸는 경우
CONTACT_EMAIL만 변경합니다.
테스트용:
CONTACT_EMAIL = yjh@bmpretty.com
운영용:
CONTACT_EMAIL = bmp@bmpretty.com

발신 계정까지 바꾸는 경우
아래 두 항목을 반드시 함께 변경합니다.
SMTP_USER = bmp@bmpretty.com
SMTP_PASSWORD = bmp 계정의 실제 비밀번호
SMTP_USER만 바꾸고 비밀번호를 기존 계정 비밀번호로 두면 인증 오류가 발생합니다.
현재 정상 동작 중이라면 보통 아래 값은 변경하지 않습니다.
SMTP_HOST = outbound.daouoffice.com
SMTP_PORT = 465

환경 변수 변경 후 적용
환경 변수 변경 후:
Save
→ Deployments
→ 최신 배포 선택
→ Redeploy
환경 변수는 저장만 해서는 기존 배포에 적용되지 않습니다. 반드시 새로 배포해야 합니다.
GitHub에 새 커밋을 push해도 자동으로 새 배포가 시작됩니다.

보안 관련 주의사항
로컬 비밀번호는 프로젝트 최상위의 다음 파일에 저장합니다.
.env.local
현재 .gitignore에 다음 내용이 있으므로 GitHub에는 올라가지 않습니다.
.env*
GitHub에 올리기 전 확인:
git status
목록에 .env.local이 보이지 않아야 정상입니다.
비밀번호는 다음 위치에 직접 작성하면 안 됩니다.
app/page.js
app/api/contact/route.js
GitHub README
메신저 또는 공개 문서

문의 메일 오류 확인 방법
실제 홈페이지에서 메일 전송 실패가 나오면 Vercel에서 확인합니다.
Vercel→ bmp-tech-homepage→ Logs
문의하기 버튼을 다시 누른 후 /api/contact의 오류를 확인합니다.
대표 오류:
127.0.0.1:465
SMTP_HOST가 배포에 적용되지 않은 경우이므로 환경 변수 확인 후 Redeploy합니다.
535 Authentication failed
SMTP_USER 또는 SMTP_PASSWORD가 잘못된 경우입니다.
ESOCKET 또는 ECONNECTION
SMTP 서버 주소, 포트 또는 외부 접속 문제를 확인합니다.
